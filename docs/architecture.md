# 프로젝트 구조와 개발 방향

- `app/__init__.py`: Flask 앱 생성 및 설정
- `app/routes.py`: 분실물 목록, 등록, 상세 조회 요청 처리
- `app/db.py`, `app/schema.sql`: SQLite 연결 관리와 테이블 생성
- `app/templates/`: 한국어 HTML 화면
- `app/static/css/`: 화면 스타일
- `instance/`: 실행 중 생성되는 로컬 DB (Git 제외)
- `tests/`: 독립적인 임시 DB를 사용하는 기능 테스트
- `run.py`: 개발 실행 진입점

요청은 라우트 → SQLite 조회/저장 → Jinja HTML 렌더링 순서로 처리합니다.
현재는 습득한 물품을 게시하는 로컬 개발용 기본 구조입니다.
DB 초기화 명령은 기존 데이터를 삭제하지 않습니다. 스키마 변경에 따른 마이그레이션은 별도로 도입해야 합니다.

## 다음 개발 항목

- 학교 계정 로그인과 관리자 권한
- 등록 폼 CSRF 보호
- 물품 분류, 검색 및 페이지 나누기
- 습득일, 보관 장소 및 반환 상태 관리
- 본인 확인 후 반환하는 업무 흐름
- 사진 업로드와 파일 검증

학교에 공개 배포하기 전 로그인, 권한, CSRF 보호를 구현하고 운영 서버 설정을 추가합니다.
