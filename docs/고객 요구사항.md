# 고객 요구사항 — 교내 분실물 관리 서비스

## 1. 문제와 목표

분실 학생은 물품의 보관 여부와 위치를 알기 어려워 행정실 방문을 반복한다. 행정 담당자는 같은 물건에 대한 반복 문의를 받고, 물품 등록과 인도 상태 관리에 부담을 느낀다.

서비스의 목표는 다음과 같다.

- 학생이 방문 전에 물품의 보관 여부·위치와 문의 방법을 확인한다.
- 행정 담당자가 필요한 물품 정보를 등록하고 보관 중인 물품과 인도 완료 물품을 구분한다.
- 등록 업무의 부담을 줄인다. 현재 소요 시간과 개선 목표 수치는 아직 정하지 않았다.

## 2. 이해관계자

|이해관계자|관심과 역할|
|---|---|
|분실 학생|잃어버린 물건의 보관 여부와 위치를 확인하고 싶다.|
|습득 학생|주운 물건을 어디에 맡겨야 하는지 알고 싶다.|
|행정 담당자|물품을 등록하고 보관·인도 상태를 관리한다.|
|정보보호 담당자|조회 시 공개할 정보의 범위를 검토한다.|
|학생회|학생의 불편과 개선 의견을 전달한다.|
|학교의 서비스 운영 책임자|운영 정책과 책임을 결정한다. 실제로 누가 맡는지는 확인해야 한다.|

## 4. 개발 범위와 공통 제약

|범위 ID|내용|근거|구분|사유와 남은 확인 사항|
|---|---|---|---|---|
|SC1|분실물 보관 여부와 위치 조회|S1|포함|학생이 방문 전에 확인한다. 검색 조건과 공개 정보는 추가로 정한다.|
|SC2|분실물 정보 등록|S2|포함|조회할 물품 정보를 등록·관리한다. 필수 입력 항목은 추가 확인한다.|
|SC3|보관 중·인도 완료 상태 구분|S2|포함|이미 인도한 물건과 보관 중인 물건을 구분한다. 처리 권한과 정정 방법은 확인한다.|
|SC4|습득물을 맡길 장소 안내|S3|미정|기존 안내가 있는지, 프로그램 안내가 필요한지 확인한다.|
|SC5|사진을 올려 비슷한 분실물 조회|S5|제외|사진 등록·비교 기능까지 개발 범위가 확대되므로 후속 개선 후보로 남긴다.|
|SC6|보관 담당자에게 문의할 방법 안내|S5|포함|담당 부서와 문의 방법을 표시한다. 구체적인 표시 내용은 확인한다.|
|SC7|사진 매칭 결과를 분실 학생에게 자동 알림|S5|제외|수신 정보 등록과 발송이 필요하다. 이번에는 문의 방법 안내까지 개발한다.|
|SC8|개인 휴대전화 번호 공개|S4·S5|제외|담당 부서의 문의 방법 안내와 구분한다.|

**C_1 — 공통 제약:** 가상 데이터를 사용하며 실제 개인정보와 학교 인증 연동은 제외한다.
